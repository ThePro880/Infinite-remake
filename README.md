Infinite Remake (v1.0.0)

A lightweight, clean Chrome extension for Infinite Craft (neal.fun/infinite-craft) that adds a Challenge Wheel with difficulty tiers, Speedrun tracking, Achievements, Trophy Cards, Custom Workspace Themes, Merge Particles, Backups, and a built-in MP3 Radio — all styled to match the original game's minimalist UI.

Features

- Challenge Mode & Speedrun HUD:
  - Mission Wheel with All / Easy / Medium / Hard difficulty filters and custom challenges.
  - Automatic detection on exact target merges, streak tracking (Streak & Best Streak), and saved personal records.
  - Draggable Speedrun HUD with timer, step counter, and Clean View mode.
- Achievements & Trophy Cards:
  - 10 unlockable medals with live progress tracking.
  - Downloadable First Discovery Trophy Card (.png) featuring your discovery name, time, steps, and streak.
- Visual Lab & Effects:
  - 6 built-in themes (Original, Grid Paper, Parchment, Dark Chalkboard, Blueprint, Neon Lab).
  - Custom crafting area solid color with Auto-sync dark sidebar & cards, custom Image/GIF background with darken slider, and an option to hide default background lines.
  - 4 merge particle styles (Sparks, Stars, Retro Pixels, Bubbles) with rainbow or custom colors, plus confetti bursts and synthesized sound effects.
- MP3 Radio & Backups:
  - Persistent background MP3 player (stored locally in IndexedDB) with playlist, volume, and playback speed (0.5x–2.0x).
  - One-click Export / Import .json backup for your achievements, records, themes, and custom challenges.
  - Draggable floating Infinite Remake button (defaults above the bottom-left Menu button).

Hotkeys

- F8: Start / Pause Speedrun Timer
- F9: Reset Current Run
- Alt + R: Open / Close Infinite Remake Panel
- Alt + H: Toggle Clean View (Hide/Show HUD)
- Alt + M: Play / Pause Background Radio

Installation (Chrome / Edge / Brave)

1. Download the latest infinite-remake-v1.0.0.zip from the Releases section (or click Code -> Download ZIP).
2. Extract the .zip file to a folder on your PC.
3. Open chrome://extensions in your browser.
4. Enable Developer mode (top-right corner).
5. Click Load unpacked and select the extracted folder containing manifest.json.
6. Open Infinite Craft (https://neal.fun/infinite-craft/) and refresh the page (Ctrl + F5).
