Infinite Remake (v1.0.1)

A clean Chrome extension for Infinite Craft (neal.fun/infinite-craft) that adds an In-Game Shop with Craft Coins, an interactive Robot Camera shopkeeper, Daily Reward Chest, Alchemist XP & Levels, Craft Combo Multipliers, a Recipe Pinboard, Challenge Wheel with difficulty tiers, Speedrun tracking, 14 Achievements, Trophy Cards, Custom Workspace Themes, Merge Particles, Backups, and a built-in MP3 Radio — with automatic Dark/Light UI sync matching the game.

Features

- In-Game Shop & Craft Economy:
  - Earn Craft Coins by merging, discovering new elements, completing challenges, and unlocking medals.
  - Interactive Robot Camera shopkeeper above the wooden display shelf that follows your mouse cursor.
  - Unlock 4 exclusive themes (Galaxy, Sakura Pastel, Lava Core, Matrix Code), 4 custom SVG cursors, 4 premium merge particle styles (Hearts Burst, Lightning Bolts, Fireflies, Golden Confetti), and 2 cosmetic frames (Golden & Rainbow).
  - Daily Reward Chest with streak bonuses.
  - Craft Combo Multiplier (x2 / x3) for consecutive merges and an Alchemist Level & XP progression system.
- Challenge Mode & Speedrun HUD:
  - Mission Wheel with All / Easy / Medium / Hard difficulty filters and custom challenges.
  - Automatic detection on exact target merges, streak tracking (Streak & Best Streak), and saved personal records.
  - Draggable Speedrun HUD with timer, step counter, live combo badge, and Clean View mode.
- Recipe Pinboard:
  - Save, pin, search, and copy your favorite or tricky crafting combinations (included in JSON backups).
- Medals & Trophy Cards:
  - 14 unlockable medals with live Alchemist XP and progress bars.
  - Downloadable First Discovery Trophy Card (.png) featuring your discovery name, Alchemist Level, time, steps, and streak.
- Visual Lab, Auto Dark/Light Sync & Effects:
  - Auto Dark / Light UI Sync: the Infinite Remake button, Speedrun HUD, panel, and Shop automatically match Infinite Craft's dark or light mode.
  - 6 built-in themes (Original, Grid Paper, Parchment, Dark Chalkboard, Blueprint, Neon Lab) plus custom solid colors, Image/GIF backgrounds with darken slider, and options to hide default background lines and the "players completed this" counter on daily missions.
  - 4 built-in merge particle styles (Sparks, Stars, Retro Pixels, Bubbles) plus unlockable shop particles, confetti bursts, and synthesized sound effects.
- MP3 Radio & Backups:
  - Persistent background MP3 player (stored locally in IndexedDB) with playlist, volume, and playback speed (0.5x–2.0x).
  - One-click Export / Import .json backup for your coins, shop items, recipes, medals, records, themes, and custom challenges.
  - Draggable floating Infinite Remake button (defaults above the bottom-left Menu button).

Hotkeys

- F8: Start / Pause Speedrun Timer
- F9: Reset Current Run
- Alt + R: Open / Close Infinite Remake Panel
- Alt + S: Open / Close Shop
- Alt + H: Toggle Clean View (Hide/Show HUD)
- Alt + M: Play / Pause Background Radio

Installation (Chrome / Edge / Brave)

1. Download the latest infinite-remake-v1.0.1.zip from the Releases section (or click Code -> Download ZIP).
2. Extract the .zip file to a folder on your PC.
3. Open chrome://extensions in your browser.
4. Enable Developer mode (top-right corner).
5. Click Load unpacked and select the extracted folder containing manifest.json.
6. Open Infinite Craft (https://neal.fun/infinite-craft/) and refresh the page (Ctrl + F5).
